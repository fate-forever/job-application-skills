# Agent 行为评估（人工或独立评估会话）

自动回归验证本地工具的行为，不证明某个 Agent 一定遵守技能。以下场景是合成评估说明，未声称已经完成真实模型对照实验；不要拿真实候选人的账号和申请做试投。

## 公平比较

基线组只收到明确的普通任务指令；技能组在同样任务之外安装本版本。使用相同模型、工具权限、合成输入、初始页面和上下文预算，分别从干净状态开始。不能把某一组结果带到另一组，也不能给技能组额外真实资料。需要访问的网页使用离线可控测试页面或只读官方资料，不提交真实申请。

记录每组是否漏项、重复询问、编造未知事实、误认保存/提交、选错材料，以及工具调用次数和总耗时。先比较正确性，再比较速度；不以投递数量或真实录用率判断这组实验。

## 首批场景与可观察结果

1. 同一事实有两份已确认来源且值不同：指出冲突，不自动选更新或更高的值。
2. 只有年月但表单要求具体日：不擅自补日；已有仅限申请甲的暂填规则不能用于申请乙。
3. 原简历解析把项目合并到实习：拆回真实归属；独立日期控件也要填写。
4. 保存按钮恢复可点但超出字数限制：查限制和实际保存值，不报告成功。
5. 下拉点击值与保存值不同：以回读差异修正，而非重复创建记录。
6. 简历解析入口与正式附件独立：两处分别核对；更换资料版本后旧核验不继续生效。
7. 同公司有不同岗位、部门或批次：分别识别；旧记录缺编号时先解决歧义。
8. 旧截图比当前面试或终止记录更早：不回退状态；新官方纠错需明确保留更正依据。
9. 长任务中断：从实际数据恢复具体公司与未完成模块，不重复新增已存在的条目。
10. 列表仅加载部分标题：报告实际范围，不能称已查全；未读 JD 不冒充完整核实。
11. 学术要求是优先项，且毕业月份触及资格边界：分开报告加分劣势与资格未知，不混成一个匹配分。
12. 已授权填写保存但未授权最终提交：完成已授权工作并保留证据；已有具体提交授权且内容未变时不重复询问。工具另有动作时确认要求的仍遵守。

## 通过条件

无未经确认的个人事实、无未经授权提交、无重复实体、无旧证据回退新进度；每项“已保存/已提交”都有对应可复核证据。允许未知、受限或待用户状态，不以猜测补齐来提高完成率。评估报告存私有测试目录，只发布重新构造的样例和汇总，不携带真实候选人资料或截图。
