# 求职 Agent Skills（脱敏开源版）

用真实候选人资料筛岗、持续查公司和填写中文网申的可复用流程。公开版只包含通用技能、空模板和工具源码；个人资料由使用者在自己的私有工作区提供。

## 内容

- `skills/jobhuntbot`：岗位推荐、排序、简历选择、申请边界及可选本地看板；保留空模板与看板源码。
- `skills/company-job-screening`：按公司池持续核实官方岗位、去重、保存研究记录与断点；附只读状态检查脚本。
- `skills/resume-application`：复用已确认个人资料，填写、保存和回读中文网申。
- `integrations/boss-crawler.md`：已有 BOSS 工具的上游安装入口；该第三方工具独立安装，本包不携带其程序和资产。

普通岗位推荐不授权网申、投递或台账写入。填写与最终提交的授权分别判断；只在成功证据出现后记录已投递。

## 安装和使用

把需要的 `skills/<技能名>` 文件夹复制到 Agent 支持的技能目录，或让 Agent 直接读取对应 `SKILL.md`。复制前检查同名目录，备份现有版本，避免覆盖自己的定制技能。技能运行时通过用户提供的工作区获取个人资料，不依赖本机绝对路径。

可按下面方式提问：

```text
使用 $jobhuntbot，根据我提供的简历和官方 JD 推荐岗位，只做建议。
使用 $company-job-screening，逐家公司查这份公司池，每发现一个匹配岗位就保存到我指定的本地文档。
使用 $resume-application，填写并核对当前官方网申，保存后先不要提交。
```

浏览招聘官网需要可用网页工具；实际填表需要可用浏览器或电脑操作工具。工具名随 Agent 环境而异。没有浏览器权限时可以准备资料和草稿，不宣称已填写网页。

## 私有资料配置

已有资料与台账时直接沿用，无需初始化新系统。需要空模板时，在使用者工作区创建 `private/`，将 `examples/workspace-config.example.json` 复制为 `private/workspace.json`，按需复制候选人、筛岗空模板为配置指向的文件。未使用的可选路径保持空字符串。所有相对路径以该工作区为基准。

`candidate-data.example.json` 完全为空；不内置任何人的姓名、联系方式、学历、成绩、实习或申请选择。源模板不能当作已确认事实。需要家庭或身份字段时，按当前表单和授权在私有主档中补充，不改公开技能。

## 可选看板

使用者可在私有工作区复制 `skills/jobhuntbot/dashboard/` 为自己的看板目录，再从 `skills/jobhuntbot/templates/dashboard-template/` 复制空 CSV。在该私有目录运行 `node server.js`，打开 `http://localhost:8420/dashboard.html`。需要 Node.js，不需要安装第三方包。服务仅绑定本机。

包内 CSV 只含表头；运行后的申请数据不应回写公开模板。

## 脱敏与检查

本包按文件白名单整理，没有复制原工作区、Git 历史、简历、证件、成绩证明、截图、申请台账、聊天、缓存、浏览器状态或 API 配置。带有个人事实的流程段落已改为用户配置与通用判断，原来的自用技能不修改。

运行以下命令检查常见敏感数据、文件类型与空模板约束：

```text
python scripts/check_public_package.py
```

检查不会打印命中内容。扫描是辅助检查；新增文件、填写模板或修改公开包后需要重新复核。`.gitignore` 不能移除已经被跟踪的文件，也不能代替检查。本次检查结果见 `PRIVACY_REVIEW.md`。
