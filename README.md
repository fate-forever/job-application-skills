# 求职 Agent Skills · v2

帮助 Agent 根据真实资料筛岗、持续查公司和填写中文网申。三个技能可分别安装；公开仓库只包含通用流程、空模板、工具源码与虚构测试，不包含候选人履历或投递记录。

## 可以做什么

- `jobhuntbot`：核对官方资格、比较岗位与简历版本，预览有证据的台账变更。
- `company-job-screening`：按公司池持续查岗位，记录实际查阅范围、去重、保存与恢复断点。
- `resume-application`：按来源与申请范围复用资料，建立本次申请资料包，核对字段、条目、日期控件和附件的保存结果。

BOSS 爬取工具独立安装，入口见 [可选集成](integrations/boss-crawler.md)。本包不包含该第三方工具的程序、登录状态、截图或编译资产。

## 下载与安装

下载仓库 ZIP 后解压，或克隆本仓库。可以直接让 Agent 读取 `skills/技能名/SKILL.md`，也可以把所需技能文件夹复制到当前 Agent 支持的技能目录。每个技能自己的模板、引用和脚本均随文件夹一起安装，不依赖仓库根目录的例子或另一技能的安装路径。

可选安装工具需要 Python 3.10 或更新版本，只用标准库。`DESTINATION` 替换为你选定的技能目录：

```text
python scripts/install_skills.py --dest DESTINATION
python scripts/install_skills.py --dest DESTINATION --skill resume-application --apply
```

第一条只预览；加 `--apply` 才复制。目标有同名技能时整次操作停止，不覆盖或删除已有版本。升级时自行备份后选择新的空目标，不把私人配置复制到公开源码。

## 最小开始方式

不需要先填写所有模板。推荐岗位只需相关简历、目标和官方来源；持续找岗再指定公司池与保存位置；实际填表才需要相应个人资料和可用浏览器。

```text
使用 $jobhuntbot，根据我的简历和官方 JD 比较岗位，只做建议，说明首选与未核实条件。
使用 $company-job-screening，按这份公司名单继续筛岗，新发现保存到我指定的文档，保留断点。
使用 $resume-application，复用已确认资料填写当前官方网申，按模块保存并回读核验，先不要提交。
```

推荐和研究本身不授权填表、修改投递台账或最终提交。已有明确授权覆盖的动作直接继续；目标、材料或高影响答案改变时再核对。具体浏览器工具要求的动作当时确认仍按其规则处理。

搜索官网需要可用网页工具，实际填表需要浏览器或电脑操作工具。没有工具权限时只能准备建议或草稿，不能报告已完成网页动作。本地脚本不增加浏览器权限，也不自动调用模型或招聘平台。

## v2 的实际改进

- **有来源的资料复用**：真实事实和单次表单答案分开，保留日期精度、确认时间和明确更正关系；不同已确认来源冲突时不凭更新时间猜值。
- **固定本次材料版本**：申请资料包记录目标、授权范围、选定简历校验值和模块预期；主档或材料变动后旧核验作废。
- **检查保存结果**：对照实际回读值、稳定条目编号、日期、网站限制和附件版本，发现差异才修复。按钮变化和完整度百分比不算保存证据。
- **先看台账变更**：JSON/CSV 字段可映射，按岗位、部门和批次去重；旧证据、身份歧义、重复实体和状态回退被标为冲突。工具只预览，仍由原系统在授权范围写入。
- **资格保留未知**：毕业月份跨越日级边界、缺少官方来源、专项规则不适用时不默认通过；论文优先项不当成硬门槛。
- **可恢复的研究**：断点与数据校验值关联，检查分页覆盖声明、未读 JD 和待同步项；记录总数不等于可投岗位数。

这些工具检查的是用户或 Agent 提供的数据与证据记录，不能独立证明官网当前状态、用户确实授权或证据本身真实。岗位职责匹配仍需要阅读完整 JD，不生成录用概率。

## 模板和命令在哪里

- 网申资料与回读：[资料约定](skills/resume-application/references/data-contract.md)。空模板和命令随该技能安装。
- 岗位资格、台账预览：[本地工具说明](skills/jobhuntbot/references/local-tools.md)。
- 公司池和断点：[资料入口](skills/company-job-screening/references/workspace.md)。

仓库根目录 `examples/` 是便捷副本；单独安装时使用各技能自带模板。旧版主档和现有台账可以继续使用，不会自动迁移。需要脚本检查时先在私有工作区做最小映射，保留原始资料。

可选看板继续提供于 `skills/jobhuntbot/dashboard/`。复制到私有工作区，再从 `templates/dashboard-template/` 复制空 CSV，运行 `node server.js`，打开 `http://localhost:8420/dashboard.html`。仅绑定本机；看板不是技能前置条件。

## 测试与隐私

```text
python -B -m unittest discover -s tests -v
python -B scripts/check_public_package.py
python -B scripts/check_public_package.py --git-history
```

自动化测试使用虚构人物字段、合成公司、岗位与日期，覆盖资料冲突、保存差异、身份去重、旧状态回退、资格边界、安装与隐私检查。它们不是实站投递测试，也不能替代 Agent 的实际行为评估；公平比较方法见 [行为评估](tests/BEHAVIORAL_EVAL.md)。

受限环境可以把 `JOB_SKILLS_TEST_TMPDIR` 指向一个允许写入的测试临时目录。测试不读取任何真实简历、证件、浏览器资料或投递记录。

私有主档、申请资料包、回读截图、认证配置和运行记录放在自己的私有目录，不回写模板。扫描会检查文件内容与文件名；历史模式另查历史文件、提交说明和作者邮箱。可用 `--denylist-json` 指定位于包外的私人标识列表，命中时不回显内容。自动扫描是辅助检查，新增文件后仍需复核；`.gitignore` 不会清除已经提交的文件。

版本校验清单见 `MANIFEST.json`，检查范围见 [隐私复核](PRIVACY_REVIEW.md)。MIT 许可及第三方归属见 [LICENSE](LICENSE) 和 [来源说明](THIRD_PARTY_NOTICES.md)。
