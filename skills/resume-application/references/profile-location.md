# 私有资料入口

本技能只提供流程与本地核验工具。首次使用确认用户工作区、主档、简历素材、选定版本及已有核对记录。私有路径记录在用户自己的配置中，不修改公共技能来写入个人身份。

没有主档且用户需要新建时，从本技能 `templates/candidate-data.example.json` 建立版本 2 私有资料；字段说明与命令见 [资料与核验约定](data-contract.md)。已有格式直接复用，不自动迁移或复制全量隐私。

只读当前模块需要的信息。读取来源、确认时间、原始精度、用途和范围；已解决的旧待办不再重复索要。临时答案只对应真实申请，不能跨公司当成默认事实。路径失效仅在用户指定目录寻找替代，仍缺失则说明位置，不扫描整个磁盘或云端。

本人输入并保存的值注明 `user_entered_saved`，不提升成证书已验证。主档、截图、申请资料包与浏览器状态都是私有数据，不放入技能或公共仓库。
