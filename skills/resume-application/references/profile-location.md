# 使用者自己的资料入口

本技能只提供流程。首次使用时确认用户指定工作区、结构化主档、简历素材、目标版本简历和已有核对记录。私有路径保存在使用者自己的配置中，不修改公共技能来填写身份信息。

本包根目录的 `examples/workspace-config.example.json` 与 `examples/candidate-data.example.json` 可用作空模板；不要求迁移已存在的主档。路径相对用户指定工作区。技能安装目录中的文件不作为私人信息副本。

主档按需包含基础信息、教育、实习、项目、资格、奖项及申请上下文。用户未要求且当前表单不需要的家庭、住址等资料不用收集。字段可附 `source`、`confirmed_at`、`reuse`、`as_of`；`application_contexts` 只适用于对应申请，不覆盖全局偏好。

读取前确认版本与来源，失效路径只在用户指定目录内寻找替代；仍缺失则说明所需文件，不扫描整个磁盘或云盘。只输出核对所需摘要，不回显完整敏感主档。
