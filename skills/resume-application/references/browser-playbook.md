# 浏览器填写与保存

使用当前环境提供的浏览器工具，先读其初始化与操作规则。定位、控件类型、下拉选项来自最新可见页面，不硬编码历史标签页编号、字段序号或隐藏接口。

## 按模块填写

把已确认条目整理一次，在工具允许的范围内顺序填写相邻字段。下拉、自动补全和日期控件先观察实际选项；依赖项出现前不猜值。意外弹窗或导航出现时停止本批，检查当前状态后续填。

保存后一起读回该模块全部字段、条目数、日期和校验提示。网站不同模块可能不共享简历，个人简历、岗位申请、专项申请与正式附件分别核实。暂存允许缺必填，不代表通过预览或提交校验。

## 日期、文本与静默失败

- 日期框可能只读，点击后另有弹窗输入框。先观察实际 DOM，再填写并读主字段；不复制其他网站的定位器。
- 编辑文本后读完整实际值，防止旧文拼接；必要时全选、删除、再填。保存回读要确认旧内容消失。
- 没有错误提示不代表保存成功。检查字数上限、必填、异步状态与最终记录。下拉点击后也要核对保存值。
- 等待实际记录加载再判断空表；不要因首次空白就重复新增。结果未知先离开再进入查重，仅修复缺失或错误项。
- 上传用于自动解析与正式附件可能是不同入口。确认主简历和正式附件均为选定版本；重新解析后复核所有手工修正项。

## 证据与交接

截图仅保留必要页面区域，避免完整证件号、验证码、家庭和住址。未知身份、法律或声明答案集中交给用户；验证与登录按当前工具允许范围处理，不绕过网站控制。

核对记录包括公司/岗位、资料版本、核对时间、模块、保存状态、缺项、回读证据和实际提交结果。不能将点击、暂存或已附文件记作提交成功。
