# 私有资料入口与能力边界

本技能不内置候选人身份、学校、任职、成绩、偏好或投递历史。

首次使用时，从用户指定的工作区或资料入口确认：当前简历、结构化主档、经历证据、材料版本映射和最新投递记录。不要扫描整个磁盘。未提供资料时只询问影响当前任务的信息；普通推荐不读取证件、家庭和完整住址。

资料入口可放在使用者工作区的 `private/workspace.json`。本技能自带 `templates/candidate_profile.template.json` 是可选空模板，字段见 [资料约定](profile-contract.md)，不是运行前提。技能安装目录与工作区不同，所有私有路径相对使用者指定工作区解释。

最新用户确认优先；按具体事实处理来源冲突，保留来源、日期、原始精度、是否进行中及适用申请。单家公司选择不能覆盖全局偏好。临时结束日期不能覆盖已确认的在职状态。

经历判断从当前资料建立，不预设求职方向。区分本人实现和团队结果、离线试验和生产上线、结构有效率和准确率、框架使用和底层研发；不混合不同评测集、指标口径或不同版本数字。
